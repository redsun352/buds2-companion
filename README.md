# Buds2 Companion

Android companion app for inspecting paired Galaxy Buds2 Bluetooth audio connection state.

## APK

Every push to `main` runs the Android release build in GitHub Actions. The generated APK is published as a workflow artifact.

## Scope

The app uses Android Bluetooth APIs for paired-device and audio-profile state. It does not claim to implement Samsung's proprietary Buds2 control protocol.
